# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and constructive; assume good intent.
- No harassment, discrimination, personal attacks, or publishing others'
  private information (including tokens, endpoints, or hostnames from shared logs).
- Keep discussion focused on the project.

## Enforcement

Report unacceptable behavior privately to the maintainer via a
[GitHub security advisory](https://github.com/shashidhanekula96/dgx-lab/security/advisories/new)
(mark it as a conduct report) or by contacting the maintainer through their
GitHub profile. Reports are handled confidentially. The maintainer may remove
comments, commits, or contributions and may ban contributors who violate this
code, following the Contributor Covenant enforcement guidelines.
